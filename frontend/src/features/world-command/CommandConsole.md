# Command Console

## Overview

The command console provides a tabbed interface for exploring live events, propagation analysis, AI insights, world memory, and the AI command input.

## Tabs

| Tab | Content |
|-----|---------|
| LIVE EVENTS | Real-time event feed |
| PROPAGATION | Risk propagation paths |
| AI ANALYSIS | AI-generated insights |
| WORLD MEMORY | Historical analogues |
| COMMAND | AI command input |

## Command Input

The command input accepts natural language queries to control the globe. Supported commands include:

- Country names for focus
- Route queries: "route from X to Y"
- Risk queries: "show risk in X"
- Supply chain queries: "show supply chain for X"
- Map queries: "show map"

## Tab Switching

The active tab can be controlled via URL search params: `?tab=events`, `?tab=propagation`, `?tab=analysis`, `?tab=memory`, `?tab=command`.
