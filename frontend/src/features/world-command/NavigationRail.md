# Navigation Rail

## Overview

The navigation rail provides vertical access to all major sections of MarketAtlas.

## Items

| Label | Icon | Destination |
|-------|------|-------------|
| WORLD | Globe | `/dashboard` |
| MARKETS | TrendingUp | `/markets` |
| EVENTS | Radio | `/dashboard?tab=events` |
| GRAPH | Network | `/graph` |
| SIMULATOR | FlaskConical | `/simulator` |
| MEMORY | Database | `/memory` |
| AGENTS | Bot | `/dashboard?tab=agents` |
| ATLAS | Orbit | `/atlas` |

## Features

- Active item is highlighted with accent color
- AGENTS shows a pulse dot when agents are analyzing
- Reset button at the bottom clears the globe focus
- Each item has a tooltip title on hover
