# Security Policy

## Supported Versions
MarketAtlas security patches are applied to the latest `main` branch.

## Reporting a Vulnerability
If you discover a security vulnerability within MarketAtlas, please report it via GitHub Private Vulnerability Reporting or email the security maintainers directly.

Please include:
1. Detailed description of the issue.
2. Steps or proof-of-concept to reproduce the vulnerability.
3. Impact assessment.

We strive to acknowledge reports within 48 hours and provide a remediation timeline promptly.
